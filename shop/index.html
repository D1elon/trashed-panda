Questions

When will my order arrive?

Each item is printed when you order it and then shipped, and you’ll see a delivery estimate at checkout. For the holidays, order early: the cut-off date is shown at the top of this page.

Can I return something?

Everything is made to order, so we can’t take returns for a change of mind. If an item arrives damaged, misprinted or in the wrong size, contact us within 30 days and we’ll replace it.

How do the sizes run?

All apparel is a unisex fit, so if you usually wear women’s sizes, go one size down. Socks come in S/M and L/XL, and the beanie is one size. Want the ugly sweater extra cosy? Size up.

Is this official?

Trashed Panda is an independent fan project inspired by a true story. It isn’t affiliated with Virginia ABC, Hanover County or, as far as we know, the raccoon.
